<dash>
name: $userBanner
desc: Возвращает URL-адрес баннера профиля пользователя.
category: Информация

<block type="text" title="Как работает команда?">
text: Без аргумента $userBanner возвращает баннер учётной записи бота. При указании ID пользователя или его упоминания она возвращает баннер этого пользователя. Анимированные баннеры возвращаются как URL-адреса GIF, остальные — как URL-адреса PNG.
</block>

<block type="code" title="Синтаксис">
text: $userBanner[(user_id)]
</block>

<block type="code" title="Готовый пример для копирования">
text: $userBanner[123456789012345678]
</block>

<block type="callout" kind="warning">
text: У пользователя должен быть баннер профиля, а бот должен иметь возможность получить данные пользователя. Перед поиском из необязательного ID удаляются все символы, кроме цифр.
</block>

<block type="callout" kind="note">
text: Встроенная форма использует только кэшированных пользователей. Самостоятельная форма может запросить пользователя, который сейчас не находится в кэше. По умолчанию всегда выбирается учётная запись бота, а не автор, запустивший скрипт.
</block>
</dash>

<details>
syntax: $userBanner[(user_id)]
param: userID|snowflake|Необязательный|ID или упоминание пользователя; по умолчанию используется учётная запись бота
</details>
