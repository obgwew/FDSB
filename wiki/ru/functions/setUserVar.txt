<dash>
name: $setUserVar
desc: Сохраняет постоянное значение в области пользователя и сервера.
category: Переменные

<block type="text" title="Как работает команда?">
text: $setUserVar сохраняет значение в файле переменных пользователей под ключом guild_id:user_id. С двумя аргументами используются автор, запустивший скрипт, и текущий сервер. Чтобы выбрать другого пользователя, добавьте ID пользователя, а чтобы выбрать другой сервер — ID сервера. Команду нельзя использовать встроенно.
</block>

<block type="code" title="Синтаксис">
text: $setUserVar[name; value; (user_id); (guild_id)]
</block>

<block type="code" title="Готовый пример для копирования">
text: $setUserVar[points; 10; 123456789012345678; 987654321012345678]
</block>

<block type="callout" kind="important">
text: Если глобальная переменная с таким именем не существует, команда сохраняет переданное значение для пользователя, создаёт пустое глобальное определение, а затем останавливает скрипт с ошибкой окружения. Сначала определите глобальную переменную.
</block>
</dash>

<details>
syntax: $setUserVar[name; value; (user_id); (guild_id)]
param: name|text|Обязательный|Имя переменной
param: value|text|Обязательный|Сохраняемое значение
param: userID|snowflake|Необязательный|ID пользователя; по умолчанию используется автор, запустивший скрипт
param: guildID|snowflake|Необязательный|ID сервера; по умолчанию используется текущий сервер
</details>
