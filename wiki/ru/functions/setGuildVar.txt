<dash>
name: $setGuildVar
desc: Сохраняет постоянное значение в области сервера.
category: Переменные

<block type="text" title="Как работает команда?">
text: $setGuildVar сохраняет значение в файле переменных гильдии под выбранным ID сервера. Если передан только обязательный аргумент со значением, используется текущий сервер; при передаче третьего аргумента ID сервера выбирается явно. Команду нельзя использовать встроенно.
</block>

<block type="code" title="Синтаксис">
text: $setGuildVar[name; value; (guild_id)]
</block>

<block type="code" title="Готовый пример для копирования">
text: $setGuildVar[welcomeMessage; Welcome!; 123456789012345678]
</block>

<block type="callout" kind="important">
text: Если глобальная переменная с таким именем не существует, команда сохраняет переданное значение для сервера, создаёт пустое глобальное определение, а затем останавливает скрипт с ошибкой окружения. Перед назначением значений в области сервера определите глобальную переменную.
</block>
</dash>

<details>
syntax: $setGuildVar[name; value; (guild_id)]
param: name|text|Обязательный|Имя переменной
param: value|text|Обязательный|Сохраняемое значение
param: guildID|text|Необязательный|ID сервера; по умолчанию используется текущий сервер
</details>
