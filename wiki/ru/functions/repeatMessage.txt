<dash>
name: $repeatMessage
desc: Повторяет фрагмент текста заданное число раз и отправляет результат одним сообщением.
category: ⁨Математика и числа⁩

<block type="text" title="Как работает команда?">
text: ⁨$repeatMessage⁩ принимает целое число и фрагмент текста, затем отправляет этот текст столько раз подряд. Сама по себе она выводит повторённый результат, а внутри другой команды повторённый текст подставляется на своё место, что удобно для создания узоров и разделителей. Пишите ⁎\s⁎ там, где между повторениями нужен пробел.
</block>

<block type="list" title="Как использовать в приложении">
item: Откройте вкладку «Команды»
item: Нажмите +, чтобы начать новую команду
item: Введите имя в поле «Название»
item: Задайте поле «Префикс»
item: Вставьте приведённый ниже код в редактор
item: Нажмите «Сохранить»
</block>

<block type="code" title="Синтаксис">
text: $repeatMessage[amount; message]
</block>

<block type="code" title="Готовый пример для копирования">
text: $repeatMessage[5; ★]
</block>

<block type="options" title="Правила">
option: amount|Целое число 1 или больше. Для 0 ничего не отправляется.
option: message|Текст для повторения. Пишите ⁎\s⁎ для пробела.
</block>

<block type="callout" kind="note">
text: Discord ограничивает одно сообщение 2000 символами, поэтому повторения проверяются до отправки. Если amount, умноженный на длину текста, превысит этот предел, команда остановится и попросит использовать меньше повторений или более короткий текст.
</block>
</dash>

<details>
syntax: $repeatMessage[amount; message]
param: amount|number|Required|Сколько раз повторить текст. Должно быть целым числом 1 или больше.
param: message|text|Required|Текст для повторения. Пишите ⁎\s⁎ для пробела.
</details>
