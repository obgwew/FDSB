<dash>
name: $getGuildVar
desc: Получает постоянную переменную в области сервера.
category: Переменные

<block type="text" title="Как работает команда?">
text: $getGuildVar сначала ищет переопределение для конкретного сервера в файле переменных гильдии. Если переопределения нет, используется глобальная переменная с тем же именем. При одном аргументе используется текущий сервер, а при двух ID сервера выбирается явно.
</block>

<block type="code" title="Синтаксис">
text: $getGuildVar[name; (guild_id)]
</block>

<block type="code" title="Готовый пример для копирования">
text: $getGuildVar[welcomeMessage]
</block>

<block type="callout" kind="important">
text: Если глобальная переменная не существует, команда создаёт запись-заполнитель, при необходимости создаёт запись для сервера и прерывает выполнение скрипта с ошибкой окружения. Проверьте переменную и задайте её перед использованием.
</block>

<block type="callout" kind="note">
text: Команду получения можно использовать встроенно и как самостоятельную инструкцию. Отсутствующее глобальное значение не считается молча допустимым.
</block>
</dash>

<details>
syntax: $getGuildVar[name; (guild_id)]
param: name|text|Обязательный|Имя получаемой переменной
param: guildID|text|Необязательный|ID сервера, значение переменной в области которого нужно прочитать; по умолчанию используется текущий сервер
</details>
