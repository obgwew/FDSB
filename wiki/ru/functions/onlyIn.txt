<dash>
name: $onlyIn
desc: Разрешает команде выполняться только в перечисленных каналах или на серверах, а в любом другом месте показывает ваше собственное сообщение.
category: Контроль доступа

<block type="text" title="Как работает команда?">
text: $onlyIn проверяет, где команда была использована, ещё до того, как что-либо выполнится. Перечислите разрешённые каналы и серверы, а затем завершите сообщением, которое должны увидеть все остальные. Если команда использована в одном из них, ничего не происходит и остальная часть команды продолжает выполняться. В любом другом месте сообщение отправляется, а остальная часть команды там же обрывается.
</block>

<block type="list" title="Как использовать в приложении">
item: Откройте вкладку «Команды»
item: Нажмите +, чтобы начать новую команду
item: Введите имя в поле «Имя»
item: Заполните поле «Префикс»
item: Вставьте приведённый ниже код в редактор
item: Нажмите «Сохранить»
</block>

<block type="code" title="Синтаксис">
text: $onlyIn[channel or server ID or name; ...; error message]
</block>

<block type="code" title="Пример для копирования">
text: $onlyIn[123456789012345678; general; Use this command in #general.]
text: $sendMessage[Welcome!]
</block>

<block type="options" title="Что можно перечислить">
option: channel ID|ID канала, например 123456789012345678, со знаком # или без него
option: channel name|Название канала, например general
option: server ID or name|ID или название сервера, чтобы команда работала и в соответствующем канале этого сервера
</block>

<block type="callout" kind="note">
text: Сообщение ставьте последним — всё, что идёт после записей, считается одним сообщением. Указав название сервера, вы разрешаете команду в любом канале этого сервера.
</block>

<block type="callout" kind="important">
text: Проверка смотрит на канал, в котором команда была набрана. В личном сообщении нет ни канала, ни сервера для сопоставления, поэтому там команда всегда блокируется.
</block>
</dash>

<details>
syntax: $onlyIn[channel or server ID or name; ...; error message]
param: channel or server ID or name|text|Обязательный|Один или несколько ID каналов, названий каналов, ID серверов или названий серверов, которые разрешены.
param: error message|text|Обязательный|Сообщение, отправляемое в канал, когда команда использована в другом месте. Всё, что идёт после записей, считается этим сообщением.
</details>
