<dash>
name: $resetGuildVar
desc: Удаляет переопределение переменной для сервера.
category: Переменные

<block type="text" title="Как работает команда?">
text: $resetGuildVar удаляет значение, сохранённое для конкретного сервера под указанным именем переменной. Она не удаляет и не изменяет определение глобальной переменной. С одним аргументом используется текущий сервер, а со вторым аргументом ID сервера выбирается явно.
</block>

<block type="code" title="Синтаксис">
text: $resetGuildVar[name; (guild_id)]
</block>

<block type="code" title="Готовый пример для копирования">
text: $resetGuildVar[welcomeMessage; 123456789012345678]
</block>

<block type="callout" kind="note">
text: Если переопределение для сервера уже отсутствует, команда безопасно завершается без изменений и записывает это состояние в журнал выполнения.
</block>
</dash>

<details>
syntax: $resetGuildVar[name; (guild_id)]
param: name|text|Обязательный|Имя переменной, для которой нужно удалить переопределение сервера
param: guildID|text|Необязательный|ID сервера; по умолчанию используется текущий сервер
</details>
