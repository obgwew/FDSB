<dash>
name: $getLeaderboardValue
desc: Возвращает сохранённый счёт участника или сервера в таблице лидеров, либо 0, если для него ничего не сохранено.
category: Переменные

<block type="text" title="Как работает команда?">
text: $getLeaderboardValue берёт тот же рейтинг, который строят команды таблицы лидеров, и возвращает счёт одного участника или сервера. Отсутствующая запись, отсутствующее значение или значение, не являющееся числом, — всё это даёт 0.
</block>

<block type="list" title="Как использовать в приложении">
item: Сначала создайте переменную на вкладке «Переменные»
item: Откройте вкладку «Команды»
item: Нажмите +, чтобы начать новую команду
item: Введите имя в поле «Имя»
item: Заполните поле «Префикс»
item: Вставьте приведённый ниже код в редактор
item: Нажмите «Сохранить»
</block>

<block type="code" title="Синтаксис">
text: $getLeaderboardValue[type; name; sort; id]
</block>

<block type="code" title="Пример для копирования">
text: $sendMessage[You have #$getLeaderboardValue[user; points; desc] points.]
</block>

<block type="options" title="Типы переменных">
option: user|Одно значение на участника, хранится отдельно в каждом сервере
option: globaluser|Одно значение на участника, общее для всех серверов, где находится бот
option: server|Одно значение на сервер
</block>

<block type="options" title="Типы сортировки">
option: desc|Сначала наибольшее значение (используется, если сортировка оставлена пустой)
option: asc|Сначала наименьшее значение
</block>

<block type="callout" kind="note">
text: Оставьте ID пустым, чтобы прочитать значение того, кто запустил команду. Для типа server этим значением по умолчанию становится текущий сервер. Значения, не являющиеся числами, возвращают 0.
</block>
</dash>

<details>
syntax: $getLeaderboardValue[type; name; sort; (id)]
param: type|text|Обязательный|Какой набор ранжировать: user, globaluser или server.
param: name|text|Обязательный|Имя переменной, по которой идёт ранжирование.
param: sort|text|Обязательный|desc для «сначала наибольшие» или asc для «сначала наименьшие».
param: id|snowflake|Необязательный|Кого или какой сервер искать. По умолчанию — тот, кто запустил команду, а для типа server — текущий сервер.
</details>
