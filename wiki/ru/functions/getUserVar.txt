<dash>
name: $getUserVar
desc: Получает постоянную переменную в области пользователя на сервере.
category: Переменные

<block type="text" title="Как работает команда?">
text: $getUserVar проверяет переопределение пользователя, сохранённое под ключом guild_id:user_id. Если это переопределение пустое или отсутствует, используется глобальная переменная. С одним аргументом используются автор, запустивший скрипт, и текущий сервер; два аргумента задают ID пользователя, а три — ID пользователя и сервера.
</block>

<block type="code" title="Синтаксис">
text: $getUserVar[name; (user_id); (guild_id)]
</block>

<block type="code" title="Готовый пример для копирования">
text: $getUserVar[points; 123456789012345678]
</block>

<block type="callout" kind="important">
text: Если глобальная переменная не существует, команда создаёт запись-заполнитель, при необходимости создаёт запись для пользователя и прерывает выполнение скрипта. Сначала определите глобальную переменную.
</block>

<block type="callout" kind="note">
text: Команду получения можно использовать встроенно или как самостоятельную инструкцию. По умолчанию выбирается автор, запустивший скрипт, а не бот.
</block>
</dash>

<details>
syntax: $getUserVar[name; (user_id); (guild_id)]
param: name|text|Обязательный|Имя получаемой переменной
param: userID|text|Необязательный|ID пользователя, значение переменной в области которого нужно прочитать; по умолчанию используется автор, запустивший скрипт
param: guildID|text|Необязательный|ID сервера; по умолчанию используется текущий сервер
</details>
