<dash>
name: $resetUserVar
desc: Удаляет переопределение переменной для пользователя.
category: Переменные

<block type="text" title="Как работает команда?">
text: $resetUserVar удаляет переопределение, сохранённое под ключом guild_id:user_id. Она не удаляет и не изменяет определение глобальной переменной. С одним аргументом используются автор, запустивший скрипт, и текущий сервер; два аргумента задают ID пользователя, а три — ID пользователя и сервера.
</block>

<block type="code" title="Синтаксис">
text: $resetUserVar[name; (user_id); (guild_id)]
</block>

<block type="code" title="Готовый пример для копирования">
text: $resetUserVar[points; 123456789012345678]
</block>

<block type="callout" kind="note">
text: Если переопределение уже отсутствует, команда безопасно завершается без изменений и записывает это состояние в журнал выполнения.
</block>
</dash>

<details>
syntax: $resetUserVar[name; (user_id); (guild_id)]
param: name|text|Обязательный|Имя переменной, для которой нужно удалить переопределение пользователя
param: userID|text|Необязательный|ID пользователя; по умолчанию используется автор, запустивший скрипт
param: guildID|text|Необязательный|ID сервера; по умолчанию используется текущий сервер
</details>
