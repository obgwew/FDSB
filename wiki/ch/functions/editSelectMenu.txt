<dash>
name: $editSelectMenu
desc: 编辑现有选择菜单的最小/最大选择数以及占位符文本。
category: 组件

<block type="text" title="命令如何工作？">
text: $editSelectMenu 通过菜单 ID 在消息上找到选择菜单，并更新用户必须/可以选择的选项数量（Min/Max）以及做出选择之前显示的提示文本（Placeholder）。已添加到菜单中的选项保持不变。要编辑单个选项，请使用 $editSelectMenuOption。
</block>

<block type="code" title="语法">
text: $editSelectMenu[Menu ID; Min; Max; (Placeholder; Message ID)]
</block>

<block type="code" title="可复制示例">
text: $newSelectMenu[color_menu; 1; 1; Pick a color]
$addSelectMenuOption[color_menu; Red; red; The color red]
$addSelectMenuOption[color_menu; Blue; blue; The color blue]
$editSelectMenu[color_menu; 1; 2; Pick one or two colors]
</block>

<block type="callout" kind="note">
text: 如果不指定 Message ID，机器人会先在交互来源消息上查找菜单，然后在机器人发送的最后一条消息上查找。菜单选项会被保留。
</block>

<block type="callout" kind="warning">
text: Min 必须在 0 到 25 之间，Max 必须在 1 到 25 之间，且 Min 不能大于 Max。目标消息必须是由该机器人发送的，并且必须已包含具有给定 ID 的菜单。
</block>
</dash>

<details>
syntax: $editSelectMenu[Menu ID; Min; Max; (Placeholder; Message ID)]
param: Menu ID|text|Required|要编辑的选择菜单的 ID
param: Min|number|Required|用户必须选择的新最小选项数（0 到 25）
param: Max|number|Required|用户可以选择的新的最大选项数（1 到 25）
param: Placeholder|text|Optional|做出选择之前显示的新的提示文本
param: Message ID|snowflake|Optional|包含要编辑菜单的特定机器人消息的 ID
</details>
