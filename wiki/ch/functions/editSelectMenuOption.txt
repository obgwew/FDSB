<dash>
name: $editSelectMenuOption
desc: 编辑现有选择菜单选项的标签、值、描述、默认状态或表情符号。
category: 组件

<block type="text" title="命令如何工作？">
text: $editSelectMenuOption 通过当前值（Value）在某个选择菜单内找到选项，然后更新其标签、描述、默认状态和/或表情符号。Value 参数必须与要编辑的选项的值匹配。将 Default 设置为 yes 会使该选项成为唯一的预选选项。
</block>

<block type="code" title="语法">
text: $editSelectMenuOption[Menu ID; Label; Value; Description; (Default; Emoji; Message ID)]
</block>

<block type="code" title="可复制示例">
text: $newSelectMenu[color_menu; 1; 1; Pick a color]
$addSelectMenuOption[color_menu; Red; red; The color red]
$addSelectMenuOption[color_menu; Blue; blue; The color blue]
$editSelectMenuOption[color_menu; Crimson; red; A deep red]
</block>

<block type="callout" kind="note">
text: 该命令会在目标消息上实时更新选项。如果不指定 Message ID，它会先在交互来源消息上查找，然后在机器人发送的最后一条消息上查找。
</block>

<block type="callout" kind="warning">
text: 如果菜单中不存在具有给定 Value 的选项，则会返回错误。目标消息必须是由该机器人发送的，并且必须包含具有给定 ID 的选择菜单。
</block>
</dash>

<details>
syntax: $editSelectMenuOption[Menu ID; Label; Value; Description; (Default; Emoji; Message ID)]
param: Menu ID|text|Required|包含该选项的选择菜单的 ID
param: Label|text|Required|向用户显示的此选项的新文本
param: Value|text|Required|要编辑的选项的当前值（用于定位该选项）
param: Description|text|Emptiable|显示在标签下方的新的小段描述
param: Default|yes/no|Optional|yes 表示将其设为预选选项（默认：no）
param: Emoji|text|Optional|显示在选项标签旁的新的表情符号
param: Message ID|snowflake|Optional|包含要编辑菜单的特定机器人消息的 ID
</details>
