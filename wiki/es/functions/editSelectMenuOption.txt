<dash>
name: $editSelectMenuOption
desc: Reescribe una entrada dentro de un menú que ya está en un mensaje que publicó el bot.
category: Componentes

<block type="text" title="¿Cómo funciona el comando?">
text: Los menús se montan una opción a la vez, y esto cambia una sola de ellas después del hecho. El bot encuentra la entrada por el valor que le diste cuando se creó la opción, y luego cambia por una etiqueta nueva, una descripción pequeña nueva, un emoji nuevo, o la marca como la que empieza preseleccionada. El menú se actualiza en el mensaje donde ya está, así que nadie tiene que ejecutar tu comando de nuevo para ver la diferencia.
</block>

<block type="list" title="Cómo usarlo en la aplicación">
item: Abre la pestaña de comandos
item: Toca + para crear un comando nuevo
item: Ponle un nombre en el campo Nombre
item: Establece el prefijo !renamecolor en el campo Prefijo
item: Pega el código de abajo en el editor
item: Toca Guardar
</block>

<block type="code" title="Sintaxis">
text: $editSelectMenuOption[Menu ID; Label; Value; Description; (Default; Emoji; Message ID)]
</block>

<block type="code" title="Ejemplo listo para copiar">
text: $newSelectMenu[color_menu; 1; 1; Pick a color]
text: $addSelectMenuOption[color_menu; Red; red; The color red]
text: $addSelectMenuOption[color_menu; Blue; blue; The color blue]
text: $editSelectMenuOption[color_menu; Crimson; red; A deep red]
</block>

<block type="callout" kind="note">
text: El valor es como se localiza la opción, así que tiene que coincidir con lo que escribiste cuando se añadió la opción, no con lo que desearías que fuera. Deja el ID del mensaje fuera y el bot comprueba primero el mensaje de la interacción, luego el último.
</block>

<block type="callout" kind="warning">
text: Si ninguna opción lleva ese valor, el comando se detiene con un error. Marcar una como predeterminada borra la preselección en todas las demás, ya que un menú solo puede empezar con una sola elección.
</block>
</dash>

<details>
syntax: $editSelectMenuOption[Menu ID; Label; Value; Description; (Default; Emoji; Message ID)]
param: Menu ID|text|Obligatorio|ID del menú al que pertenece la opción
param: Label|text|Obligatorio|El texto nuevo que los miembros ven en el menú
param: Value|text|Obligatorio|El valor que la opción ya tiene, usado para encontrarla
param: Description|text|Puede quedar vacío|La línea pequeña nueva que se muestra bajo la etiqueta
param: Default|yes/no|Opcional|Escribe yes para que esta opción empiece ya elegida (predeterminado: no)
param: Emoji|text|Opcional|Muestra este emoji junto a la etiqueta
param: Message ID|snowflake|Opcional|Qué mensaje del bot contiene el menú. Déjalo fuera para usar el evidente.
</details>
