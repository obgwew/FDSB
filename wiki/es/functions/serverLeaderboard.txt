<dash>
name: $serverLeaderboard
desc: Crea una clasificación que ordena servidores entre sí según una puntuación guardada.
category: Variables

<block type="text" title="¿Cómo funciona el comando?">
text: $serverLeaderboard lee una variable que guarda una puntuación por servidor y alinea los servidores de mayor a menor puntuación. Envía la lista ordenada al canal. Úsalo para competiciones entre servidores donde cada servidor intenta superar a los demás con la misma medida.
</block>

<block type="list" title="Cómo usarlo en la aplicación">
item: Crea la variable primero en la pestaña de Variables
item: Abre la pestaña de comandos
item: Toca + para crear un comando nuevo
item: Ponle un nombre en el campo Nombre
item: Establece el campo Prefijo
item: Pega el código de abajo en el editor
item: Toca Guardar
</block>

<block type="code" title="Sintaxis">
text: $serverLeaderboard[name; (sort); (limit); (format)]
</block>

<block type="code" title="Ejemplo listo para copiar">
text: $serverLeaderboard[serverPoints; desc; 10]
</block>

<block type="options" title="Tipos de orden">
option: desc|Valor más alto primero (se usa cuando dejas el orden vacío)
option: asc|Valor más bajo primero
</block>

<block type="options" title="Marcadores de línea">
option: {rank}|La posición, empezando en 1
option: {name}|Nombre del servidor
option: {mention}|La ID del servidor
option: {id}|ID de Discord del servidor
option: {value}|La puntuación guardada
</block>

<block type="callout" kind="note">
text: Solo se pueden clasificar números, así que las entradas que contienen texto se dejan fuera. El límite puede ir de 1 a 25 y se limita por ti; cualquier valor más alto se recorta.
</block>
</dash>

<details>
syntax: $serverLeaderboard[name; (sort); (limit); (format)]
param: name|text|Obligatorio|Nombre de la variable que guarda una puntuación por servidor.
param: sort|text|Opcional|desc para el valor más alto primero (por defecto), o asc para el más bajo primero.
param: limit|number|Opcional|Cuántas líneas mostrar, de 1 a 25. Por defecto 10.
param: format|text|Opcional|Plantilla de línea. Por defecto {rank}. {name} — {value}. Puedes usar {rank}, {name}, {mention}, {id} y {value}.
</details>
