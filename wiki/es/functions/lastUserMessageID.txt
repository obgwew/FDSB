<dash>
name: $lastUserMessageID
desc: Te entrega el ID del mensaje que puso en marcha tu comando.
category: Variables

<block type="text" title="¿Cómo funciona el comando?">
text: Esto rellena el ID del mensaje que activó el comando — el que llevaba tu prefijo. Sigue igual durante toda la ejecución, así que las líneas de más abajo, o una función que llames después, todas ven el mismo número. Por sí solo el número significa poco para quien lee el chat, así que normalmente se envuelve dentro de un mensaje o se entrega a otro comando que trabaja con IDs.
</block>

<block type="list" title="Cómo usarlo en la aplicación">
item: Abre la pestaña de comandos
item: Toca + para crear un comando nuevo
item: Ponle un nombre en el campo Nombre
item: Establece el prefijo !welcome en el campo Prefijo
item: Escribe tu script en el editor
item: Pega la línea de abajo donde la necesites
item: Toca Guardar
</block>

<block type="code" title="Sintaxis">
text: $lastUserMessageID
text: $lastUserMessageID[]
</block>

<block type="code" title="Ejemplo listo para copiar">
text: $sendMessage[Your message ID is $lastUserMessageID]
</block>

<block type="callout" kind="note">
text: Es un valor y no una acción, así que solo hace algo cuando está dentro de otro comando. En una línea por sí solo no hay nada que enviar.
</block>
</dash>
