<dash>
name: $awaitedCommand
desc: Ejecuta tu script cuando alguien responde después de que $awaitInput pidiera una respuesta.
category: Evento

<block type="text" title="¿Cómo funciona el evento?">
text: Este evento trabaja en pareja con $awaitInput. Establece el campo Prefijo en $awaitedCommand[name], usando el mismo nombre que le diste a $awaitInput, y las líneas de abajo se ejecutan en el momento en que llega la respuesta esperada.
text: Añade un filtro opcional tras un punto y coma dentro de los corchetes para decidir qué respuestas se aceptan. `<numeric>` acepta números enteros y decimales, mientras que `<yes/no>` acepta solo las palabras que enumeres, separadas por barras e ignorando las mayúsculas. Sin ningún filtro, cualquier respuesta despierta el script.
</block>

<block type="list" title="Cómo usarlo en la aplicación">
item: Abre la pestaña de comandos
item: Toca + para crear un comando nuevo
item: Ponle un nombre en el campo Nombre
item: Establece el campo Prefijo en $awaitedCommand[age]
item: La aplicación lo marca como evento por ti
item: Pega el código de abajo en el editor
item: Toca Guardar
</block>

<block type="code" title="Sintaxis">
text: #PREFIX:$awaitedCommand[name]
text: #PREFIX:$awaitedCommand[name;<numeric>]
text: #PREFIX:$awaitedCommand[name;<yes/no>]
</block>

<block type="code" title="Ejemplo listo para copiar">
text: #PREFIX:$awaitedCommand[age;<numeric>]
text: $sendMessage[Got it, you are $message years old.]
</block>

<block type="callout" kind="note">
text: La respuesta en sí es el mensaje sobre el que se ejecuta el script, así que $message contiene el texto que escribió el miembro. Varios scripts que esperan el mismo nombre se ejecutan todos, primero el archivo más antiguo, siempre que cada uno acepte la respuesta.
</block>

<block type="callout" kind="important">
text: El nombre tiene que coincidir con el que se le dio a $awaitInput, y tiene que haber una espera activa en ese canal. Sin una espera en curso, un mensaje nunca despierta este script. Pon el prefijo en la primera línea, o la aplicación dejará de tratar el archivo como un evento.
</block>
</dash>

<details>
syntax: $awaitedCommand[waitName; (filter)]
param: waitName|text|Obligatorio|El nombre usado por la línea $awaitInput correspondiente
param: filter|text|Opcional|Envuélvelo entre corchetes angulares: numeric para números, o una lista como yes/no/true/false
</details>
