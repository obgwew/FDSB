<dash>
name: $resetGuildVar
desc: Clears the value one server keeps for a variable.
category: Variables

<block type="text" title="How does the command work?">
text: Each server can hold its own value for a variable you made in the Variables tab. $resetGuildVar throws that per-server value away, so the variable falls back to the default everyone else sees, and the variable itself stays exactly where it was. Name it on its own and the server where the command ran is the one cleared; put a server ID after a semicolon and that server is cleared instead.
</block>

<block type="list" title="How to use it in the app">
item: Create the variable first in the Variables tab
item: Open the Commands tab
item: Tap + to start a new command
item: Give it a name in the Name field
item: Set the Prefix field to $resetGuildVar
item: Paste the code below into the editor
item: Tap Save
</block>

<block type="code" title="Syntax">
text: $resetGuildVar[name; (guild_id)]
</block>

<block type="code" title="Ready-to-copy Example">
text: $resetGuildVar[welcomeMessage; 123456789012345678]
</block>

<block type="callout" kind="note">
text: If that server never had its own value there is nothing to remove, and the bot notes the state and carries on instead of stopping.
</block>
</dash>

<details>
syntax: $resetGuildVar[name; (guild_id)]
param: name|text|Required|The variable whose value for that server should be cleared
param: guildID|text|Optional|Which server to clear it for; defaults to the server you are in
</details>
