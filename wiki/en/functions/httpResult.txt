<dash>
name: $httpResult
desc: Reads back the answer your bot got from its last web request.
category: HTTP

<block type="text" title="How does the command work?">
text: $httpResult picks up whatever the last web request brought back and hands it to you. With nothing inside the brackets you get the whole answer, laid out as text when it is an object or a list. Add parts to walk into it: a name picks a field, a number picks an item out of a list, and you can chain as many of them as you need to dig further down.
</block>

<block type="list" title="How to use it in the app">
item: Open the Commands tab
item: Tap + to start a new command
item: Give it a name in the Name field
item: Set the Prefix field to !weather
item: Write your script in the editor
item: Paste the line below wherever you need it
item: Tap Save
</block>

<block type="code" title="Syntax">
text: $httpResult[(key1; key2; ...)]
</block>

<block type="code" title="Ready-to-copy Example">
text: $httpGet[https://api.example.com/users]
text: $httpResult[0; username]
</block>

<block type="callout" kind="note">
text: Numbers pick a position in a list, names pick a field in an object. Ask for something that is not there and you simply get an empty result rather than an error, so nothing at all shows in the message.
</block>
</dash>

<details>
syntax: $httpResult[(key1; key2; ...)]
param: key|text|Optional|Which field or position to walk into in the answer. Repeat it for values further down.
</details>
