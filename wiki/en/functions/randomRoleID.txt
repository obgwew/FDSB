<dash>
name: $randomRoleID
desc: Picks one of the server's roles at random and hands back its ID.
category: Randomness

<block type="text" title="How does the command work?">
text: The bot gathers every role in the current server, sets one of them aside at random and gives you that role's ID. The @everyone role never comes up, since it belongs to everybody and picking it would tell you nothing. What you get is a bare run of digits, ready to drop into another line that needs a role.
</block>

<block type="list" title="How to use it in the app">
item: Open the Commands tab
item: Tap + to start a new command
item: Give it a name in the Name field
item: Set the Prefix field to $randomRoleID
item: Write your script in the editor
item: Paste the line below wherever you need it
item: Tap Save
</block>

<block type="code" title="Syntax">
text: $randomRoleID
</block>

<block type="code" title="Ready-to-copy Example">
text: Random role ID: $randomRoleID
</block>

<block type="callout" kind="note">
text: Roles only exist inside a server, so this cannot be used in a private message. A server with no roles of its own gets an error rather than a result.
</block>
</dash>
