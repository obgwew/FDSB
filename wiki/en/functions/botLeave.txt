<dash>
name: $botLeave
desc: Removes the bot from a server.
category: Server

<block type="text" title="How does the command work?">
text: Run it with nothing after it and the bot walks out of the server the command was used in, straight away.
text: Give it a server ID instead and that server is the one it leaves, which even works from a private chat as long as the bot is still a member there.
text: A server ID that is not plain digits, or one the bot has not joined, is turned down with an error in the channel.
</block>

<block type="list" title="How to use it in the app">
item: Open the Commands tab
item: Tap + to start a new command
item: Give it a name in the Name field
item: Set the Prefix field to !leave
item: Paste the code below into the editor
item: Tap Save
</block>

<block type="code" title="Syntax">
text: $botLeave
text: $botLeave[guildID]
</block>

<block type="code" title="Ready-to-copy Example">
text: $botLeave
</block>

<block type="callout" kind="warning">
text: There is no undo from inside the chat — bringing the bot back means inviting it again through the app.
text: Outside a server always pass the server ID, and remember it has to be digits only.
</block>
</dash>

<details>
syntax: $botLeave[(guildID)]
param: guildID|snowflake|Optional|Which server to leave. Leave it out and the bot leaves the server the command was used in.
</details>
