<dash>
name: $onBotMessage
desc: Runs your command whenever a bot posts a message in the server.
category: Event

<block type="text" title="How does the event work?">
text: Give this command the $onBotMessage prefix and the bot picks it up as soon as any bot account posts a message in a server it is in. Messages your own bot sends are skipped by default, so it reacts to other bots only; put yes in the prefix and it follows its own messages too. Anything else there, including leaving it empty, keeps the bot's own messages out.
</block>

<block type="list" title="How to use it in the app">
item: Open the Commands tab
item: Tap + to start a new command
item: Give it a name in the Name field
item: Set the Prefix field to $onBotMessage
item: The app marks it as an Event for you
item: Paste the code below into the editor
item: Tap Save
</block>

<block type="code" title="Syntax">
text: #PREFIX:$onBotMessage[yes/no]
</block>

<block type="code" title="Ready-to-copy Example">
text: #PREFIX:$onBotMessage[no]
text: $sendMessage[Another bot said: $message]
</block>

<block type="callout" kind="note">
text: Inside the command, $message holds whatever the other bot wrote, so you can quote it, count it or pick it apart.
</block>

<block type="callout" kind="important">
text: Nobody has to type anything to set this off. The app marks the command as an Event for you and runs it on its own every time another bot posts.
</block>
</dash>

<details>
syntax: $onBotMessage[(yes/no)]
param: yes/no|text|Optional|yes to follow the bot's own messages as well, no to react only to other bots
</details>
