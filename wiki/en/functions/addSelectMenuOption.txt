<dash>
name: $addSelectMenuOption
desc: Adds one choice to a dropdown you started earlier in the same command.
category: Components

<block type="text" title="How does the command work?">
text: Every line you write puts a fresh entry into the dropdown named by the Menu ID, matched against the one you started with $newSelectMenu. People see the label with your description underneath and an optional emoji beside it, while your code only ever receives the value. Mark an entry as the default and the menu opens with it already chosen.
</block>

<block type="list" title="How to use it in the app">
item: Open the Commands tab
item: Tap + to start a new command
item: Give it a name in the Name field
item: Set the Prefix field to !ping
item: Paste the code below into the editor
item: Tap Save
</block>

<block type="code" title="Syntax">
text: $addSelectMenuOption[Menu ID; Label; Value; Description; (Default; Emoji; Message ID)]
</block>

<block type="code" title="Ready-to-copy Example">
text: $newSelectMenu[color_menu; 1; 1; Pick a color]
text: $addSelectMenuOption[color_menu; Red; red; The color red]
text: $addSelectMenuOption[color_menu; Blue; blue; The color blue; yes]
</block>

<block type="options" title="Details">
option: Default|set to yes and this choice is already selected when the menu opens
option: Emoji|an emoji shown next to the option label
option: Message ID|ID of a message the bot already sent, so its menu updates live
</block>

<block type="callout" kind="note">
text: Values inside one dropdown have to be different from each other, and an empty label or value is refused. Leave the Message ID out and the menu rides along with the message being sent; give one and the menu on that older message is rebuilt on the spot.
</block>

<block type="callout" kind="warning">
text: A dropdown holds at most 25 choices and only one of them may be the default. If the Menu ID matches nothing you started in this same command, the bot reports an error.
</block>
</dash>

<details>
syntax: $addSelectMenuOption[Menu ID; Label; Value; Description; (Default; Emoji; Message ID)]
param: Menu ID|text|Required|Which dropdown from $newSelectMenu this choice belongs to
param: Label|text|Required|The words people see in the list
param: Value|text|Required|The unique text handed back when this choice is picked
param: Description|text|Emptiable|Smaller line shown under the label
param: Default|yes/no|Optional|yes to have this choice already selected
param: Emoji|text|Optional|Emoji shown beside the label
param: Message ID|snowflake|Optional|A message the bot already sent, to rebuild its menu live
</details>
