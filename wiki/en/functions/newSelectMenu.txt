<dash>
name: $newSelectMenu
desc: Builds the dropdown menu that sits under one of your bot messages.
category: Components

<block type="text" title="How does the command work?">
text: Start a menu with an ID you invent yourself, then say how many choices a member must make and how many they are allowed to make. That ID is how every later line refers to it. The choices themselves come later, added with $addSelectMenuOption, and the finished dropdown rides along with the message you send. Hand it the ID of a bot message you have already posted and the menu lands on that message instead.
</block>

<block type="list" title="How to use it in the app">
item: Open the Commands tab
item: Tap + to start a new command
item: Give it a name in the Name field
item: Set the Prefix field to !colors
item: Paste the code below into the editor
item: Tap Save
</block>

<block type="code" title="Syntax">
text: $newSelectMenu[Menu ID; Min; Max; (Placeholder; Message ID)]
</block>

<block type="code" title="Ready-to-copy Example">
text: $newSelectMenu[color_menu; 1; 1; Pick a color]
text: $addSelectMenuOption[color_menu; Red; red; The color red]
text: $addSelectMenuOption[color_menu; Blue; blue; The color blue]
text: $sendMessage[Choose your favorite color!]
</block>

<block type="options" title="Behavior details">
option: Min|How many choices somebody has to make before it accepts
option: Max|How many choices somebody may make at once
option: Placeholder|Grey hint resting in the closed menu
option: Message ID|An already-posted bot message to drop the menu onto
</block>

<block type="callout" kind="note">
text: A menu only becomes visible once at least one choice has been added with $addSelectMenuOption. Afterwards, $editSelectMenu changes the limits or the hint and $editSelectMenuOption changes a single choice.
</block>

<block type="callout" kind="warning">
text: Min may never sit above Max. One message can carry 25 dropdowns and buttons together at the very most, and pointing at a message your bot did not send is refused.
</block>
</dash>

<details>
syntax: $newSelectMenu[Menu ID; Min; Max; (Placeholder; Message ID)]
param: Menu ID|text|Required|The name you will use for this menu later on
param: Min|number|Required|How many choices have to be made
param: Max|number|Required|The most choices that may be made
param: Placeholder|text|Optional|Grey hint seen before anything is picked
param: Message ID|snowflake|Optional|One of your own bot messages to attach this menu to
</details>
