<dash>
name: $clear
desc: Wipes a batch of recent messages out of the current channel in one sweep.
category: Moderation

<block type="text" title="How does the command work?">
text: Run it bare and the ten newest messages disappear; put a number inside and that many go instead. The bot clears them in a single request, so the channel empties at once instead of message by message. The count has to sit somewhere between 1 and 100.
</block>

<block type="list" title="How to use it in the app">
item: Open the Commands tab
item: Tap + to start a new command
item: Give it a name in the Name field
item: Set the Prefix field to !welcome
item: Write your script in the editor
item: Paste the line below wherever you need it
item: Tap Save
</block>

<block type="code" title="Syntax">
text: $clear
</block>

<block type="code" title="Ready-to-copy Example">
text: $clear[50]
</block>

<block type="callout" kind="warning">
text: Discord only lets a bot bulk-delete messages younger than two weeks, and the bot needs the Manage Messages permission in this channel. Anything outside 1 to 100 comes back as an error, and so does a number that is not a whole number.
</block>
</dash>
