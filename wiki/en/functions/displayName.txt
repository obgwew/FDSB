<dash>
name: $displayName
desc: Gives you the name a member is known by in this server.
category: User

<block type="text" title="How does the command work?">
text: If someone has set a nickname for the server, that is the name you get; without one, their account name stands in instead. Used with no brackets it describes whoever typed the command, which makes it the friendly way to greet people. Add a mention or an ID and it answers for that member instead. Either way the name lands in the channel or is filled into your own line.
</block>

<block type="list" title="How to use it in the app">
item: Open the Commands tab
item: Tap + to start a new command
item: Give it a name in the Name field
item: Set the Prefix field to $displayName
item: Write your script in the editor
item: Paste the line below wherever you need it
item: Tap Save
</block>

<block type="code" title="Syntax">
text: $displayName[(user mention/ID)]
</block>

<block type="code" title="Ready-to-copy Example">
text: Hello, $displayName!
</block>

<block type="callout" kind="note">
text: This is the per-server nickname when there is one, otherwise the account username. If you always want the account name and never the nickname, ask for $authorName.
</block>
</dash>

<details>
syntax: $displayName[(user mention/ID)]
param: user|text|Optional|Which member to name; leave empty for whoever typed the command
</details>
