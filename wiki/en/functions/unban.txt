<dash>
name: $unban
desc: Lifts a ban so the person is able to come back to the server.
category: Moderation

<block type="text" title="How does the command work?">
text: $unban takes the ID of a banned person, finds that ID in the server's ban list and takes the ban off. The person is able to rejoin with an invite straight away, and the entry is gone from the ban list for good. An ID that is not on the list is left alone, and the bot says the ban list had no such person.
</block>

<block type="list" title="How to use it in the app">
item: Open the Commands tab
item: Tap + to start a new command
item: Give it a name in the Name field
item: Set the Prefix field to !unban
item: Write your script in the editor
item: Paste the line below wherever you need it
item: Tap Save
</block>

<block type="code" title="Syntax">
text: $unban[userID]
</block>

<block type="code" title="Ready-to-copy Example">
text: $unban[123456789]
</block>

<block type="callout" kind="warning">
text: The bot needs Ban Members in that server. Only the raw number works here, so a mention or a name is refused, and so is a server where nobody under that ID is banned.
</block>

<block type="callout" kind="important">
text: In the build you are running, this line is skipped before it can act, so a ban stays in place until you lift it yourself in Discord.
</block>
</dash>

<details>
syntax: $unban[userID]
param: userID|snowflake|Required|The numeric ID of the banned person to let back in
</details>
