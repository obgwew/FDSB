<dash>
name: $editSelectMenu
desc: Edits the minimum/maximum selection and the placeholder of an existing select menu.
category: Components

<block type="text" title="How does the command work?">
text: $editSelectMenu finds a select menu by its Menu ID on a message and updates how many options the user must/may pick (Min/Max) and the hint text shown before the choice (Placeholder). The options already added to the menu stay unchanged. To edit an individual option, use $editSelectMenuOption.
</block>

<block type="code" title="Syntax">
text: $editSelectMenu[Menu ID; Min; Max; (Placeholder; Message ID)]
</block>

<block type="code" title="Ready-to-copy Example">
text: $newSelectMenu[color_menu; 1; 1; Pick a color]
$addSelectMenuOption[color_menu; Red; red; The color red]
$addSelectMenuOption[color_menu; Blue; blue; The color blue]
$editSelectMenu[color_menu; 1; 2; Pick one or two colors]
</block>

<block type="callout" kind="note">
text: Without a Message ID, the bot looks for the menu on the interaction source message first, then on the last message the bot sent. The menu options are preserved.
</block>

<block type="callout" kind="warning">
text: Min must be between 0 and 25, Max between 1 and 25, and Min cannot exceed Max. The target message must have been sent by this bot and must already contain a menu with the given ID.
</block>
</dash>

<details>
syntax: $editSelectMenu[Menu ID; Min; Max; (Placeholder; Message ID)]
param: Menu ID|text|Required|The ID of the select menu to edit
param: Min|number|Required|New minimum number of options the user must select (0 to 25)
param: Max|number|Required|New maximum number of options the user may select (1 to 25)
param: Placeholder|text|Optional|New hint text shown before a choice is made
param: Message ID|snowflake|Optional|ID of a specific bot message that holds the menu to edit
</details>
