<dash>
name: $editSelectMenu
desc: Changes how many options a menu demands and what hint it shows before anyone picks.
category: Components

<block type="text" title="How does the command work?">
text: Point this at the ID you gave a menu when you built it and the bot rewrites that menu in place on the message it is already sitting on. You can loosen or tighten how many options somebody has to choose from, and change the grey hint text above the closed menu. The options themselves are left exactly as they were, so one line turns a one-pick menu into a two-pick one.
</block>

<block type="list" title="How to use it in the app">
item: Open the Commands tab
item: Tap + to start a new command
item: Give it a name in the Name field
item: Set the Prefix field to !colors
item: Paste the code below into the editor
item: Tap Save
</block>

<block type="code" title="Syntax">
text: $editSelectMenu[Menu ID; Min; Max; (Placeholder; Message ID)]
</block>

<block type="code" title="Ready-to-copy Example">
text: $newSelectMenu[color_menu; 1; 1; Pick a color]
text: $addSelectMenuOption[color_menu; Red; red; The color red]
text: $addSelectMenuOption[color_menu; Blue; blue; The color blue]
text: $editSelectMenu[color_menu; 1; 2; Pick one or two colors]
</block>

<block type="callout" kind="note">
text: Leave the message ID out and the bot looks for the menu on the message the interaction came from first, then on the last message it sent. Either way that message has to be one the bot posted itself.
</block>

<block type="callout" kind="warning">
text: Min runs from 0 to 25, Max from 1 to 25, and Min can never sit above Max. If the message carries no menu with the ID you named, the bot says so rather than editing something else.
</block>
</dash>

<details>
syntax: $editSelectMenu[Menu ID; Min; Max; (Placeholder; Message ID)]
param: Menu ID|text|Required|The ID you gave the menu when you built it
param: Min|number|Required|How many options the user must pick, 0 to 25
param: Max|number|Required|How many options the user may pick, 1 to 25
param: Placeholder|text|Optional|New hint text shown above the menu before a choice is made
param: Message ID|snowflake|Optional|Which bot message holds the menu. Leave it out to use the obvious one.
</details>
