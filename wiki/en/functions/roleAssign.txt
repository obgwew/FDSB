<dash>
name: $roleAssign
desc: Gives a member roles, takes roles away, or does both at once.
category: Moderation

<block type="text" title="How does the command work?">
text: $roleAssign changes which roles a member is wearing. Put the member first, then list the roles you want to touch, each one starting with + to hand it over or - to take it back. The bot applies the whole list together, so the member's role bar changes in one go and the rest of your script carries on with the new roles already in place.
</block>

<block type="list" title="How to use it in the app">
item: Open the Commands tab
item: Tap + to start a new command
item: Give it a name in the Name field
item: Set the Prefix field to !role
item: Paste the code below into the editor
item: Tap Save
</block>

<block type="code" title="Syntax">
text: $roleAssign[user; +role1; -role2; ...]
</block>

<block type="code" title="Ready-to-copy Example">
text: $roleAssign[$authorID; +&123456789; -&987654321]
</block>

<block type="options" title="Role prefixes">
option: +|Hand the role over — write it as +&123456789 or +@RoleName
option: -|Take the role away — write it as -&123456789 or -@RoleName
</block>

<block type="callout" kind="note">
text: You can add and remove as many roles as you like on one line, and the member is always the first part. The bot needs Manage Roles in that server, and its own role has to sit above the roles it is handing out.
</block>

<block type="callout" kind="warning">
text: The member has to already be in the server, otherwise you get an error and nothing changes. A role that does not exist is quietly skipped, and if the bot's role sits underneath the one you are trying to change Discord turns down the whole request.
</block>
</dash>

<details>
syntax: $roleAssign[user; +role1; -role2; ...]
param: user|text|Required|The member whose roles are changing, as a user ID or a mention
param: +role1|text|Required|A role to give: a + followed by the role ID or mention, such as +&123456789
param: -role2|text|Optional|A role to take away: a - followed by the role ID or mention. Add as many + and - parts as you need.
</details>
