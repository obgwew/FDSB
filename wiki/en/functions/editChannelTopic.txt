<dash>
name: $editChannelTopic
desc: Rewrites the topic shown at the top of a server channel.
category: Channel Management

<block type="text" title="How does the command work?">
text: Give it a new topic on its own and it rewrites the one above the channel the command ran in. Add a channel ID or mention first and it rewrites that channel's topic instead, as long as the channel belongs to the same server. An empty topic clears whatever was there, and anything past 1024 characters is refused.
</block>

<block type="list" title="How to use it in the app">
item: Open the Commands tab
item: Tap + to start a new command
item: Give it a name in the Name field
item: Set the Prefix field to $editChannelTopic
item: Paste the code below into the editor
item: Tap Save
</block>

<block type="code" title="Syntax">
text: $editChannelTopic[(channel ID or mention); new topic]
</block>

<block type="code" title="Ready-to-copy Example">
text: $editChannelTopic[<#123456789012345678>; Welcome to the community!]
</block>

<block type="callout" kind="warning">
text: Only inside a server, only on channels of that server, and only where a topic exists at all. The bot also needs Manage Channels, or Discord turns the change down. Topics stop at 1024 characters.
</block>

<block type="callout" kind="note">
text: It works as a line of its own. Dropped inside another command it does nothing, so keep it on its own line.
</block>
</dash>

<details>
syntax: $editChannelTopic[(channel ID or mention); new topic]
param: channelID|text|Optional|Which channel to set the topic of; leave it out and the current channel is used
param: newTopic|text|Required|The replacement topic, up to 1024 characters. An empty value clears it
</details>
