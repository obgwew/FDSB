<dash>
name: $authorServerAvatar
desc: Gives you the picture link of a member's server avatar, or of whoever ran the command.
category: Info

<block type="text" title="How does the command work?">
text: This hands back a direct image link you can drop into a message or an embed. Leave it empty and it uses whoever triggered the command; give it a user ID or an @mention and it reads that person instead. Members who never picked a per-server picture get their ordinary avatar, and animated ones come back as .gif links.
</block>

<block type="list" title="How to use it in the app">
item: Open the Commands tab
item: Tap + to start a new command
item: Give it a name in the Name field
item: Set the Prefix field to $authorServerAvatar
item: Write your script in the editor
item: Paste the line below wherever you need it
item: Tap Save
</block>

<block type="code" title="Syntax">
text: $authorServerAvatar
text: $authorServerAvatar[(userID/@mention)]
</block>

<block type="code" title="Ready-to-copy Example">
text: Your server avatar: $authorServerAvatar
</block>

<block type="callout" kind="note">
text: A server avatar is the picture a member can change for one server only, so it often differs from their normal avatar ($authorAvatar). If the ID matches nobody the bot knows, you get an error rather than a link.
</block>
</dash>

<details>
syntax: $authorServerAvatar[(userID/@mention)]
param: userID/@mention|text|Optional|Which member to read. Leave empty for whoever ran the command.
</details>
