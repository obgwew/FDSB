<dash>
name: $httpDelete
desc: Sends a DELETE request to a web address and keeps the answer for you to read.
category: HTTP

<block type="text" title="How does the command work?">
text: The bot calls the address you hand it over HTTP DELETE and waits up to ten seconds for a reply. A body you add travels with the call, sent as JSON when it parses as JSON and as plain text when it does not. The reply body lands in $httpResult and the code in $httpStatus, and the bot prints nothing by itself.
</block>

<block type="list" title="How to use it in the app">
item: Open the Commands tab
item: Tap + to start a new command
item: Give it a name in the Name field
item: Set the Prefix field to !ping
item: Paste the code below into the editor
item: Tap Save
</block>

<block type="code" title="Syntax">
text: $httpDelete[URL; (Body)]
</block>

<block type="code" title="Ready-to-copy Example">
text: $httpDelete[https://api.example.com/users/1]
text: $httpStatus
</block>

<block type="callout" kind="note">
text: Headers you added with $httpAddHeader go out with this call and are then cleared, ready for the next request. A blocked address shows up as status 400, and a failed call as status 500 with the reason sitting in $httpResult.
</block>
</dash>

<details>
syntax: $httpDelete[URL; (Body)]
param: URL|text|Required|The address to send the DELETE call to
param: Body|text|Optional|Extra content to send along, as JSON or plain text
</details>
