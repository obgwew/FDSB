<dash>
name: $replaceText
desc: Swaps one piece of text for another inside a message.
category: String Utilities

<block type="text" title="How does the command work?">
text: Give it the original text, the piece you want gone and what should stand in its place, and the edited version comes back. Every match is swapped unless you add a fourth part holding a number, which caps how many of them get changed. Stand it on its own line and the rewritten text is posted straight into the channel.
</block>

<block type="list" title="How to use it in the app">
item: Open the Commands tab
item: Tap + to start a new command
item: Give it a name in the Name field
item: Set the Prefix field to !clean
item: Write your script in the editor
item: Paste the line below wherever you need it
item: Tap Save
</block>

<block type="code" title="Syntax">
text: $replaceText[message; old; new; (amount)]
</block>

<block type="code" title="Ready-to-copy Example">
text: $replaceText[Hello World; World; FDScript]
</block>

<block type="callout" kind="note">
text: Leave the fourth part out, or set it to -1, to catch every occurrence. Something that is not a number in that spot stops the command with an error instead of the bot guessing how many you had in mind.
</block>
</dash>

<details>
syntax: $replaceText[message; old; new; (amount)]
param: message|text|Required|The text you want to work on
param: old|text|Required|The exact piece to hunt for
param: new|text|Required|What should sit in its place
param: amount|number|Optional|How many matches to change; -1 or blank takes them all
</details>
