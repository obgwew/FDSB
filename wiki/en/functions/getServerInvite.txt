<dash>
name: $getServerInvite
desc: Produces an invite link for a server.
category: Utilities

<block type="text" title="How does the command work?">
text: On its own it makes an invite for the server the command ran in; hand it a server ID and it does that one instead. When the server already has a vanity address, that is what comes back, and otherwise the bot creates a permanent invite in the first text channel where it is allowed to. Either way the finished link is posted in the channel ready to be copied.
</block>

<block type="list" title="How to use it in the app">
item: Open the Commands tab
item: Tap + to start a new command
item: Give it a name in the Name field
item: Set the Prefix field to $getServerInvite
item: Write your script in the editor
item: Paste the line below wherever you need it
item: Tap Save
</block>

<block type="code" title="Syntax">
text: $getServerInvite
text: $getServerInvite[(guildID)]
</block>

<block type="code" title="Ready-to-copy Example">
text: Join our server: $getServerInvite
</block>

<block type="callout" kind="note">
text: The bot has to be a member of the server and be able to create invites there, otherwise it tells you it cannot make one. Leave the brackets empty and the server you are standing in is used.
</block>
</dash>

<details>
syntax: $getServerInvite[(guildID)]
param: guildID|snowflake|Optional|Which server to get an invite for. Leave it out and the current one is used.
</details>
