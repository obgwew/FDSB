<dash>
name: $return
desc: Fetches a value stored earlier by a command like $returnGuildUsersID and puts it where you use it.
category: Variables

<block type="text" title="How does the command work?">
text: A few commands gather a list of results and park it under a short name, and $return is how you ask for that name back. On its own line it prints the stored value in the channel. Written inside another command it is swapped in as plain text before that command runs, so you can drop it mid-sentence. Ask for a name nothing has put aside yet and the bot reports an error rather than inventing a value.
</block>

<block type="list" title="How to use it in the app">
item: Open the Commands tab
item: Tap + to start a new command
item: Give it a name in the Name field
item: Set the Prefix field to !lookup
item: Write your script in the editor
item: Paste the line below wherever you need it
item: Tap Save
</block>

<block type="code" title="Syntax">
text: $return[var]
</block>

<block type="code" title="Ready-to-copy Example">
text: $returnGuildUsersID[$guildID; cache; userIDs; ,]
text: $sendMessage[User IDs: $return[userIDs]]
</block>

<block type="callout" kind="note">
text: The matching command has to run first — $returnGuildUsersID before userIDs, $returnGuildChannelsID before channelIDs, and so on. The name is matched exactly, so watch the capital letters.
</block>
</dash>

<details>
syntax: $return[var]
param: var|text|Required|The name to fetch back, such as userIDs, channelIDs or roleIDs
</details>
