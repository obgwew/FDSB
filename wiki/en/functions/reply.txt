<dash>
name: $reply
desc: Makes everything the bot posts next appear as a reply to the message that triggered it.
category: Messaging

<block type="text" title="How does the command work?">
text: Stand this line above your sending commands and instead of a fresh message appearing at the bottom of the channel, each one attaches itself to the member's own message with the little reply arrow. The exchange stays in one place and it is obvious which question produced which answer. It covers everything that follows in that run of the command, not just the very next message.
</block>

<block type="list" title="How to use it in the app">
item: Open the Commands tab
item: Tap + to start a new command
item: Give it a name in the Name field
item: Set the Prefix field to !ask
item: Paste the code below into the editor
item: Tap Save
</block>

<block type="code" title="Syntax">
text: $reply
</block>

<block type="code" title="Ready-to-copy Example">
text: $reply
text: $sendMessage[This will be a reply!]
</block>

<block type="callout" kind="note">
text: If you have already pointed the command somewhere specific with $useChannel or asked for a direct message, that destination wins and the reply arrow never appears.
</block>
</dash>
