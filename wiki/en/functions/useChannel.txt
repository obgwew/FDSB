<dash>
name: $useChannel
desc: Sends everything your command writes after it into a different channel.
category: Access Control

<block type="text" title="How does the command work?">
text: $useChannel takes a server ID and a channel ID and moves the output of your command over to that channel. Everything written above it stays where it was; every message after it, plain text, cards and replies alike, is posted in the channel you named instead. It can point at a channel in a completely different server.
</block>

<block type="list" title="How to use it in the app">
item: Open the Commands tab
item: Tap + to start a new command
item: Give it a name in the Name field
item: Set the Prefix field to !useChannel
item: Write your script in the editor
item: Paste the line below wherever you need it
item: Tap Save
</block>

<block type="code" title="Syntax">
text: $useChannel[guildID; channelID]
</block>

<block type="code" title="Ready-to-copy Example">
text: $sendMessage[This goes to the current channel]
text: $useChannel[1234567890; 9876543210]
text: $sendMessage[This goes to the specified channel!]
</block>

<block type="callout" kind="note">
text: Both parts are worked out before they are checked, and both have to be plain numbers. The bot also has to be a member of the server you name and able to see the channel. Anything it cannot find is quietly skipped and noted in the log, so the rest of your command still goes to the original channel.
</block>

<block type="callout" kind="warning">
text: Once the switch is on it never turns itself off, so every later line lands in the other channel too. Behind a button press the answer to Discord is held back first, and the text goes to the target channel rather than under the button.
</block>
</dash>

<details>
syntax: $useChannel[guildID; channelID]
param: guildID|number|Required|Which server the target channel is in
param: channelID|number|Required|Which channel everything after this line should go to
</details>
