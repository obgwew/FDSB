<dash>
name: $authorName
desc: Gives you the account username of whoever typed the command.
category: Info

<block type="text" title="How does the command work?">
text: The bot reads the name off the account that sent the message and hands it over as ordinary text. Alone on a line it is posted in the channel; inside a sentence it is filled in where you wrote it. Because it reads the live name, a member who renames themselves shows the new one straight away.
</block>

<block type="list" title="How to use it in the app">
item: Open the Commands tab
item: Tap + to start a new command
item: Give it a name in the Name field
item: Set the Prefix field to $authorName
item: Write your script in the editor
item: Paste the line below wherever you need it
item: Tap Save
</block>

<block type="code" title="Syntax">
text: $authorName
</block>

<block type="code" title="Ready-to-copy Example">
text: Hello, $authorName!
</block>

<block type="callout" kind="note">
text: This is the account's own username, not the nickname someone has chosen for this server. For the per-server name, ask for $displayName instead.
</block>
</dash>
