<dash>
name: $serverIcon
desc: Gives you the picture of a server's icon.
category: Server

<block type="text" title="How does the command work?">
text: $serverIcon fetches the icon of a server and hands back the address of that picture. Used on its own it takes the server the message was sent in; give it a server ID and it uses that one instead, as long as the bot is a member there. The address drops straight into a card or goes out as a plain link, and an animated icon arrives in its moving form.
</block>

<block type="list" title="How to use it in the app">
item: Open the Commands tab
item: Tap + to start a new command
item: Give it a name in the Name field
item: Set the Prefix field to !welcome
item: Write your script in the editor
item: Paste the line below wherever you need it
item: Tap Save
</block>

<block type="code" title="Syntax">
text: $serverIcon
text: $serverIcon[(guildID)]
</block>

<block type="code" title="Ready-to-copy Example">
text: Server icon: $serverIcon
</block>

<block type="callout" kind="note">
text: A server with no icon set gives you an error instead of a blank address. The result works anywhere a picture goes, cards, thumbnails and footer icons among them, or you can just post the link on its own.
</block>
</dash>

<details>
syntax: $serverIcon[(guildID)]
param: guildID|snowflake|Optional|Which server to take the icon from. Leave it out to use the one the message was sent in.
</details>
