<dash>
name: $editSelectMenuOption
desc: Rewrites one entry inside a menu that is already sitting on a message the bot posted.
category: Components

<block type="text" title="How does the command work?">
text: Menus are put together one option at a time, and this changes a single one of them after the fact. The bot finds the entry by the value you gave it when the option was created, then swaps in a new label, a new small description, a new emoji, or ticks it as the one that starts pre-selected. The menu updates on the message where it already sits, so nobody has to run your command again to see the difference.
</block>

<block type="list" title="How to use it in the app">
item: Open the Commands tab
item: Tap + to start a new command
item: Give it a name in the Name field
item: Set the Prefix field to !renamecolor
item: Paste the code below into the editor
item: Tap Save
</block>

<block type="code" title="Syntax">
text: $editSelectMenuOption[Menu ID; Label; Value; Description; (Default; Emoji; Message ID)]
</block>

<block type="code" title="Ready-to-copy Example">
text: $newSelectMenu[color_menu; 1; 1; Pick a color]
text: $addSelectMenuOption[color_menu; Red; red; The color red]
text: $addSelectMenuOption[color_menu; Blue; blue; The color blue]
text: $editSelectMenuOption[color_menu; Crimson; red; A deep red]
</block>

<block type="callout" kind="note">
text: The value is how the option gets located, so it has to match what you typed when the option was added rather than what you wish it became. Leave the message ID out and the bot checks the interaction's own message first, then its last one.
</block>

<block type="callout" kind="warning">
text: No option carrying that value means the command stops with an error. Marking one as the default clears the pre-selection on all the others, since a menu can only start with a single choice.
</block>
</dash>

<details>
syntax: $editSelectMenuOption[Menu ID; Label; Value; Description; (Default; Emoji; Message ID)]
param: Menu ID|text|Required|ID of the menu the option belongs to
param: Label|text|Required|The new text members see in the menu
param: Value|text|Required|The value the option already has, used to find it
param: Description|text|Emptiable|The new small line shown under the label
param: Default|yes/no|Optional|Write yes to start this option already picked (default: no)
param: Emoji|text|Optional|Show this emoji beside the label
param: Message ID|snowflake|Optional|Which bot message holds the menu. Leave it out to use the obvious one.
</details>
