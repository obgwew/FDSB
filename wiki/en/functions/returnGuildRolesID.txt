<dash>
name: $returnGuildRolesID
desc: Collects the role IDs of a server into one value you can reuse.
category: Return Commands

<block type="text" title="How does the command work?">
text: $returnGuildRolesID gathers the role IDs of the server you name and glues them together under a label of your choosing. Read that label back later with $return[label] and the whole list arrives in one piece, ready to drop into a message or work through step by step. Leave the permission part empty or write all and every role comes back; name a permission instead and only the roles that hold it are listed.
</block>

<block type="list" title="How to use it in the app">
item: Open the Commands tab
item: Tap + to start a new command
item: Give it a name in the Name field
item: Set the Prefix field to !rolelist
item: Write your script in the editor
item: Paste the line below wherever you need it
item: Tap Save
</block>

<block type="code" title="Syntax">
text: $returnGuildRolesID[GuildID; permission; var; separator]
</block>

<block type="code" title="Ready-to-copy Example">
text: $returnGuildRolesID[$guildID; all; roleIDs; ,]
text: $sendMessage[Roles: $return[roleIDs]]
</block>

<block type="callout" kind="note">
text: For the permission part, leave it empty or write all to take every role, or type a permission name such as kick_members or manage_messages, or even the raw number Discord uses. A role qualifies when it holds that permission or anything stronger.
</block>

<block type="callout" kind="warning">
text: The bot has to be a member of that server, and the @everyone role is never part of the answer. If nothing in the server matches what you asked for, you get an error rather than an empty list.
</block>
</dash>

<details>
syntax: $returnGuildRolesID[GuildID; permission; var; separator]
param: GuildID|snowflake|Required|Which server to take the roles from
param: permission|text|Required|Which roles to keep: empty or all for all of them, a permission name such as kick_members, or the raw permission number
param: var|text|Required|The label the collected IDs are stored under, read back with $return[]
param: separator|text|Required|What goes between the IDs, such as a comma. Named forms: dot, com, apo, sem, colon
</details>
