<dash>
name: $createChannel
desc: Makes a new text, voice, category, forum or stage channel in the server.
category: Channel Management

<block type="text" title="How does the command work?">
text: Give the bot a name and a kind of channel and it appears in the server straight away. The kind decides what you get: a text channel, a voice channel, a category for grouping others, a forum, or a stage. Add the ID of a category as a third part and the new channel is filed inside it.
</block>

<block type="list" title="How to use it in the app">
item: Open the Commands tab
item: Tap + to start a new command
item: Give it a name in the Name field
item: Set the Prefix field to !ping
item: Paste the code below into the editor
item: Tap Save
</block>

<block type="code" title="Syntax">
text: $createChannel[name; type; (category ID)]
</block>

<block type="code" title="Ready-to-copy Example">
text: $createChannel[my-channel; text]
</block>

<block type="callout" kind="warning">
text: This only works inside a server, and the bot needs the Manage Channels permission there. Any kind other than text, voice, category, forum or stage is refused with an error.
</block>

<block type="callout" kind="note">
text: The category part is optional. Point it at something that is not a category and the bot stops with an error instead of guessing.
</block>
</dash>

<details>
syntax: $createChannel[name; type; (category ID)]
param: name|text|Required|What the new channel should be called.
param: type|text|Required|Which kind to make: text, voice, category, forum or stage.
param: categoryID|text|Optional|Category to file the new channel under.
</details>
