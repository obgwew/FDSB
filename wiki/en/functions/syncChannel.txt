<dash>
name: $syncChannel
desc: Puts a channel back on its category's permissions, undoing per-channel changes.
category: Channel Management

<block type="text" title="How does the command work?">
text: $syncChannel copies the permissions of the channel's category back onto the channel itself. With nothing after it, the channel the command was used in is the one that changes; give it a channel ID and that channel is used instead. Anything a member or a role was allowed to do differently in that channel goes away, and the category's rules apply again.
</block>

<block type="list" title="How to use it in the app">
item: Open the Commands tab
item: Tap + to start a new command
item: Give it a name in the Name field
item: Set the Prefix field to !syncChannel
item: Write your script in the editor
item: Paste the line below wherever you need it
item: Tap Save
</block>

<block type="code" title="Syntax">
text: $syncChannel[(channel ID or mention)]
</block>

<block type="code" title="Ready-to-copy Example">
text: $syncChannel[123456789012345678]
</block>

<block type="callout" kind="warning">
text: It only works inside a server, and only on a normal channel that sits inside a category. A category itself cannot be synced, a channel from another server is refused, and a channel that already matches its category is left untouched.
</block>

<block type="callout" kind="important">
text: In the build you are running, this line is skipped before it can act, so a channel keeps whatever extra permissions it had.
</block>
</dash>

<details>
syntax: $syncChannel[(channel ID or mention)]
param: channelID|snowflake|Optional|Which channel to put back on its category's rules; defaults to the current one
</details>
