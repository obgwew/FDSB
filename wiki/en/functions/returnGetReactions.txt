<dash>
name: $returnGetReactions
desc: Counts the human reactions on a message or lists who reacted, ready to read back.
category: Return Commands

<block type="text" title="How does the command work?">
text: Point it at a message and an emoji, and the bot opens that message to see who pressed that emoji. You choose whether it counts the people or writes their IDs out as one joined list, and either way the answer is parked under the storage name you gave, so nothing appears in the chat at this point. Later, $return with that same name brings the result back out as text. Bot accounts never count, whichever way you ask for it.
</block>

<block type="list" title="How to use it in the app">
item: Open the Commands tab
item: Tap + to start a new command
item: Give it a name in the Name field
item: Set the Prefix field to $returnGetReactions
item: Write your script in the editor
item: Paste the line below wherever you need it
item: Tap Save
</block>

<block type="code" title="Syntax">
text: $returnGetReactions[channelID; messageID; type; var; separator; emoji]
</block>

<block type="code" title="Ready-to-copy Example">
text: $returnGetReactions[$channelID; 123456789; usersID; reactors; ,; 👍]
</block>

<block type="callout" kind="note">
text: Ask for a count and a message where nobody used that emoji simply stores 0. Ask for the list of IDs instead and that same situation posts an error, as does a message only bots reacted to.
</block>

<block type="callout" kind="important">
text: The bot needs Read Message History in that channel, otherwise it cannot open the message and your command stops with a permissions error.
</block>
</dash>

<details>
syntax: $returnGetReactions[channelID; messageID; type; var; separator; emoji]
param: channelID|snowflake|Required|Which channel the message is sitting in
param: messageID|snowflake|Required|Which message to look at
param: type|text|Required|usersID to store who reacted, or tr to store how many people did
param: var|text|Required|What to store the result under, read back later with $return[]
param: separator|text|Required|What goes between the IDs. Words work too: dot, com, apo, sem, colon
param: emoji|text|Required|Which emoji to look for, typed the way it appears on the message
</details>
