<dash>
name: $authorAvatar
desc: Hands you the web link to a member's profile picture.
category: Info

<block type="text" title="How does the command work?">
text: Ask for it with nothing inside the brackets and you get the picture behind the profile of whoever typed the command. Give it a member's ID instead and you get theirs. What comes back is an ordinary image link, ready to be dropped into a message, an image block or a card.
</block>

<block type="list" title="How to use it in the app">
item: Open the Commands tab
item: Tap + to start a new command
item: Give it a name in the Name field
item: Set the Prefix field to $authorAvatar
item: Write your script in the editor
item: Paste the line below wherever you need it
item: Tap Save
</block>

<block type="code" title="Syntax">
text: $authorAvatar
text: $authorAvatar[(userID/@mention)]
</block>

<block type="code" title="Ready-to-copy Example">
text: Your avatar: $authorAvatar
</block>

<block type="callout" kind="note">
text: This is the picture from the person's own profile, not the one they wear inside a server — for that use $authorServerAvatar. Animated pictures come back as .gif links and everything else as .png.
</block>
</dash>

<details>
syntax: $authorAvatar[(userID/@mention)]
param: userID/@mention|text|Optional|Whose profile picture to hand back; leave empty for the person who typed the command
</details>
