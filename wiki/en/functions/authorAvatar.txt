<dash>
name: $authorAvatar
desc: Returns or sends the direct image URL of the command author's (or a user's) global avatar.
category: Info

<block type="text" title="How does the command work?">
text: $authorAvatar resolves and returns the direct image URL of a user's global (profile) avatar. Without an argument it uses the command author; with a user ID or @mention it uses that user. The result is a URL you can embed in messages or images.
</block>

<block type="code" title="Syntax">
text: $authorAvatar
text: $authorAvatar[(userID/@mention)]
</block>

<block type="code" title="Ready-to-copy Example">
text: Your avatar: $authorAvatar
</block>

<block type="callout" kind="note">
text: This uses the user's global avatar (their profile picture). For the avatar shown inside a server (guild avatar), use $authorServerAvatar. Animated avatars are returned as .gif URLs.
</block>
</dash>

<details>
syntax: $authorAvatar[(userID/@mention)]
param: userID/@mention|text|Optional|The user ID or @mention whose global avatar URL to get. If omitted, uses the command author.
</details>
