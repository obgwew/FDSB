<dash>
name: $break
desc: Ends the loop it sits in and picks up at the line after it.
category: Flow Control

<block type="text" title="How does the command work?">
text: Drop this on its own line inside a $for or a $while and the bot stops looping the moment it arrives there, carrying straight on from the first line after the matching $endfor or $endwhile. Whatever the loop still had left to do never happens. It takes no brackets and prints nothing of its own.
</block>

<block type="list" title="How to use it in the app">
item: Open the Commands tab
item: Tap + to start a new command
item: Give it a name in the Name field
item: Set the Prefix field to !search
item: Write your script in the editor
item: Paste the line below wherever you need it
item: Tap Save
</block>

<block type="code" title="Syntax">
text: $break
</block>

<block type="code" title="Ready-to-copy Example">
text: $for[10]
text:   $if[$message == stop]
text:     $break
text:   $endif
text: $endfor
</block>

<block type="callout" kind="note">
text: Only the loop you are standing in stops. If loops are wrapped inside one another, the outer ones keep turning over exactly as before.
</block>
</dash>
