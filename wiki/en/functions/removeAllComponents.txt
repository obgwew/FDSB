<dash>
name: $removeAllComponents
desc: Strips every button and menu off a message the bot sent.
category: Components

<block type="text" title="How does the command work?">
text: $removeAllComponents clears the interactive parts of a message, taking away all the buttons and select menus in one sweep and leaving plain text behind. Leave the message ID out and it works on whatever the bot is about to send or has just sent during this run. Give it a message ID and it clears that exact message instead, and the buttons disappear from the channel in front of everyone watching.
</block>

<block type="list" title="How to use it in the app">
item: Open the Commands tab
item: Tap + to start a new command
item: Give it a name in the Name field
item: Set the Prefix field to !clean
item: Paste the code below into the editor
item: Tap Save
</block>

<block type="code" title="Syntax">
text: $removeAllComponents
text: $removeAllComponents[(messageID)]
</block>

<block type="code" title="Ready-to-copy Example">
text: $removeAllComponents[123456789012345678]
</block>

<block type="callout" kind="note">
text: This is the blunt version of the job. $removeButtons and $removeComponent take single items off, while this one empties the whole row at once.
</block>

<block type="callout" kind="warning">
text: Only messages the bot itself posted can be cleared, and the ID has to be digits only. If there is nothing at all to clean, you get an error saying so instead of a silent no-op.
</block>
</dash>

<details>
syntax: $removeAllComponents[(messageID)]
param: messageID|snowflake|Optional|Which bot message to clear. Leave it out to clear the pending reply, the one behind a button click, or the last message sent.
</details>
