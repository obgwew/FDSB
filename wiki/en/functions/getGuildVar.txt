<dash>
name: $getGuildVar
desc: Reads back the value one server keeps for a variable name.
category: Variables

<block type="text" title="How does the command work?">
text: Give it a name and the bot looks for the value this particular server has set aside under it. When the server has not set one, you still get an answer: the shared value from the Variables tab stands in. Leave the second part out and it reads the server the command ran in; add a server ID and it reads that one instead.
</block>

<block type="list" title="How to use it in the app">
item: Create the variable first in the Variables tab
item: Open the Commands tab
item: Tap + to start a new command
item: Give it a name in the Name field
item: Set the Prefix field to !rules
item: Write your script in the editor
item: Paste the line below wherever you need it
item: Tap Save
</block>

<block type="code" title="Syntax">
text: $getGuildVar[name; (guild_id)]
</block>

<block type="code" title="Ready-to-copy Example">
text: $getGuildVar[welcomeMessage]
</block>

<block type="callout" kind="important">
text: Ask for a name that was never created in the Variables tab and the bot makes an empty one, posts a warning about it and stops your command right there. Get the name right first.
</block>

<block type="callout" kind="note">
text: Whatever you save from a command is still there after the bot restarts, so this is how you remember something per server rather than per person.
</block>
</dash>

<details>
syntax: $getGuildVar[name; (guild_id)]
param: name|text|Required|Which variable to read
param: guildID|text|Optional|Which server's own value to read; leave empty for the server the command ran in
</details>
