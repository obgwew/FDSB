<dash>
name: $lastUserMessageID
desc: Hands you the ID of the message that set your command running.
category: Variables

<block type="text" title="How does the command work?">
text: This fills in the ID of the message that triggered the command — the one that carried your prefix. It stays the same for the whole run, so lines further down, or a function you call later, all see the same number. On its own the number means little to anyone reading the chat, so it is normally wrapped inside a message or handed to another command that works with IDs.
</block>

<block type="list" title="How to use it in the app">
item: Open the Commands tab
item: Tap + to start a new command
item: Give it a name in the Name field
item: Set the Prefix field to !welcome
item: Write your script in the editor
item: Paste the line below wherever you need it
item: Tap Save
</block>

<block type="code" title="Syntax">
text: $lastUserMessageID
text: $lastUserMessageID[]
</block>

<block type="code" title="Ready-to-copy Example">
text: $sendMessage[Your message ID is $lastUserMessageID]
</block>

<block type="callout" kind="note">
text: It is a value rather than an action, so it only does something when it sits inside another command. On a line by itself there is nothing for it to send.
</block>
