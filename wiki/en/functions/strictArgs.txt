<dash>
name: $strictArgs
desc: Stops the command unless the person typed a particular number of words.
category: Access Control

<block type="text" title="How does the command work?">
text: Put this near the top of a command and it counts the words that came in after your prefix. If the number does not match the rule you set, the bot posts your error message and abandons the rest of the command, so nothing below it runs. When the count does match, nothing at all is printed and the command carries straight on.
</block>

<block type="list" title="How to use it in the app">
item: Open the Commands tab
item: Tap + to start a new command
item: Give it a name in the Name field
item: Set the Prefix field to !quote
item: Write your script in the editor
item: Paste the line below wherever you need it
item: Tap Save
</block>

<block type="code" title="Syntax">
text: $strictArgs[comparison; error_message]
</block>

<block type="code" title="Ready-to-copy Example">
text: $strictArgs[>2; Please provide more than 2 words!]
</block>

<block type="options" title="Comparison operators">
option: >|More than — the person must type more than N words
option: <|Fewer than — the person must type fewer than N words
option: (none)|Equal to, such as just 2 — the person must type exactly N words
option: !|Not equal to — the person must not type exactly N words
</block>

<block type="callout" kind="note">
text: Your prefix and the command name are not part of the count, so !quote hello world counts as two words. The rule has to be a number with an optional >, < or ! in front of it, and anything else is rejected before the count is even looked at.
</block>
</dash>

<details>
syntax: $strictArgs[comparison; error_message]
param: comparison|text|Required|The rule to test the word count against, such as >2, <2, 2 or !2
param: error_message|text|Required|What the bot posts when the count does not match, before stopping
</details>
