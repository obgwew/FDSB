<dash>
name: $httpPut
desc: Sends a PUT request to a web address and keeps hold of the answer.
category: HTTP

<block type="text" title="How does the command work?">
text: Give it a web address and the bot sends a PUT request there, tacking on the body when you supply one. A body that parses as JSON travels as JSON, anything else goes across as plain text. Headers you queued up with $httpAddHeader leave with this request and are cleared straight afterwards. The status code comes back in $httpStatus and the answer text in $httpResult, ready to print or reuse.
</block>

<block type="list" title="How to use it in the app">
item: Open the Commands tab
item: Tap + to start a new command
item: Give it a name in the Name field
item: Set the Prefix field to !webhook
item: Paste the code below into the editor
item: Tap Save
</block>

<block type="code" title="Syntax">
text: $httpPut[URL; (Body)]
</block>

<block type="code" title="Ready-to-copy Example">
text: $httpAddHeader[Content-Type; application/json]
text: $httpPut[https://api.example.com/users/1; {"name": "FDScript"}]
text: $httpStatus
</block>

<block type="callout" kind="note">
text: The bot gives a request ten seconds before abandoning it. One that fails reports status 500 with the error message waiting in $httpResult, while an address the bot will not reach reports 400 instead.
</block>
</dash>

<details>
syntax: $httpPut[URL; (Body)]
param: URL|text|Required|The web address to send the PUT to
param: Body|text|Optional|What to carry with the request, as JSON or plain text
</details>
