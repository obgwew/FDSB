<dash>
name: $editMessage
desc: Rewrites the text of a message the bot already sent, in any channel it can reach.
category: Messaging

<block type="text" title="How does the command work?">
text: Name a channel and a message and the bot pulls that message up and swaps its text for whatever you give it. The message has to be one the bot itself posted. Add a title, description, colour or footer afterwards and the message grows a card underneath the new text.
</block>

<block type="list" title="How to use it in the app">
item: Open the Commands tab
item: Tap + to start a new command
item: Give it a name in the Name field
item: Set the Prefix field to !ping
item: Paste the code below into the editor
item: Tap Save
</block>

<block type="code" title="Syntax">
text: $editMessage[channelID; messageID; content; (title; description; color; footer)]
</block>

<block type="code" title="Ready-to-copy Example">
text: $editMessage[$channelID; 123456789; Updated content!]
</block>

<block type="callout" kind="note">
text: Both the channel and the message come as plain numbers, not mentions. If either one matches nothing the bot can see, it says which of the two failed rather than failing quietly.
</block>

<block type="callout" kind="warning">
text: The bot needs to be able to view the channel and to edit the message inside it. Colours are given as hex values such as #FF0000.
</block>
</dash>

<details>
syntax: $editMessage[channelID; messageID; content; (title; description; color; footer)]
param: channelID|snowflake|Required|Numeric ID of the channel holding the message
param: messageID|snowflake|Required|Numeric ID of the bot message to rewrite
param: content|text|Required|The text the message should show afterwards
param: title|text|Optional|Headline for a card under the text
param: description|text|Optional|Body text for that card
param: color|text|Optional|Hex colour for that card
param: footer|text|Optional|Small footer line for that card
</details>
