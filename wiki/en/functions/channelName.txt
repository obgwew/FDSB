<dash>
name: $channelName
desc: Gives you the name of the channel the command was used in.
category: Info

<block type="text" title="How does the command work?">
text: $channelName prints the name of the channel the command came from, so your reply can talk about the room it happened in.
text: It always reports the current channel, never one you name yourself, which makes it a safe thing to drop into any message.
text: If somebody renames the channel, the very next run already shows the new name.
</block>

<block type="list" title="How to use it in the app">
item: Open the Commands tab
item: Tap + to start a new command
item: Give it a name in the Name field
item: Set the Prefix field to !here
item: Write your script in the editor
item: Paste the line below wherever you need it
item: Tap Save
</block>

<block type="code" title="Syntax">
text: $channelName
</block>

<block type="code" title="Ready-to-copy Example">
text: You are chatting in #$channelName
</block>

<block type="callout" kind="note">
text: The # sign is not part of the answer, so add it yourself as in the example when you want the name to look like a channel in the chat.
</block>
</dash>
