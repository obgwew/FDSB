<dash>
name: $addBotReactions
desc: Stamps emoji onto the message your command just sent.
category: Components

<block type="text" title="How does the command work?">
text: The bot takes the emoji you list, finds them wherever they appear in the text you passed, and reacts to the last message it sent during this run. They go on one after another, in the order you wrote them, with a short pause between each so Discord does not object. Nothing happens at all if your command has not sent a message yet, so put this below the line that does the talking.
</block>

<block type="list" title="How to use it in the app">
item: Open the Commands tab
item: Tap + to start a new command
item: Give it a name in the Name field
item: Set the Prefix field to !vote
item: Paste the code below into the editor
item: Tap Save
</block>

<block type="code" title="Syntax">
text: $addBotReactions[emoji1; emoji2; emoji3; ...]
</block>

<block type="code" title="Ready-to-copy Example">
text: $addBotReactions[✅; ❌; 🎉]
</block>

<block type="callout" kind="note">
text: The bot needs the Add Reactions permission in that channel. If Discord tells it to slow down, it waits and gives that one emoji a second try before carrying on with the rest.
</block>

<block type="callout" kind="warning">
text: Twenty emoji is the ceiling for one line. Go past it and the command stops with an error rather than reacting to anything at all.
</block>

<block type="callout" kind="important">
text: No bot message earlier in the run, or no recognisable emoji anywhere in what you passed, and the command fails on the spot with nothing added to the message.
</block>
</dash>

<details>
syntax: $addBotReactions[emoji1; emoji2; emoji3; ...]
param: emoji|text|Required|Which emoji to react with. Every emoji hiding in the text you pass is added, in order.
</details>
