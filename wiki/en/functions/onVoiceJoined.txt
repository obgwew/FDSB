<dash>
name: $onVoiceJoined
desc: Runs your lines by themselves whenever somebody joins a voice channel.
category: Event

<block type="text" title="How does the event work?">
text: $onVoiceJoined is an Event, so the app starts your lines the moment any member connects to a voice channel, with nobody typing anything. Inside them $mention and $authorID point at the member who just arrived. To have the answer land somewhere other than the voice channel, put that text channel's ID in square brackets after the prefix, the way $onVoiceJoined[123456789012345678] does.
</block>

<block type="list" title="How to use it in the app">
item: Open the Commands tab
item: Tap + to start a new command
item: Give it a name in the Name field
item: Set the Prefix field to $onVoiceJoined
item: The app marks it as an Event for you
item: Paste the code below into the editor
item: Tap Save
</block>

<block type="code" title="Syntax">
text: #PREFIX:$onVoiceJoined
</block>

<block type="code" title="Ready-to-copy Example">
text: #PREFIX:$onVoiceJoined
text:  sendMessage[$mention joined a voice channel!]
</block>

<block type="callout" kind="note">
text: Leave the square brackets out of the Prefix field and the event has no channel of its own to post in, so anything you send from it never arrives. Adding the ID there is the part that makes it work.
</block>

<block type="callout" kind="important">
text: The bot has to be a member of the server and started from the Main tab, otherwise nobody joins and nothing happens. Your lines run once per member per voice channel, so a busy server will run them often.
</block>
</dash>
