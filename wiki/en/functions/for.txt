<dash>
name: $for
desc: Runs the block of lines underneath it a set number of times.
category: Flow Control

<block type="text" title="How does the command work?">
text: Hand it a whole number and every line you place before $endfor runs exactly that many times, one after the other. Set the number to zero or below and the whole block is skipped. Anywhere inside, $break cuts the loop short and carries on with the rest of your command.
</block>

<block type="list" title="How to use it in the app">
item: Open the Commands tab
item: Tap + to start a new command
item: Give it a name in the Name field
item: Set the Prefix field to !countdown
item: Write your script in the editor
item: Paste the line below wherever you need it
item: Tap Save
</block>

<block type="code" title="Syntax">
text: $for[count]
</block>

<block type="code" title="Ready-to-copy Example">
text: $for[5]
text:   $sendMessage[Iteration!]
text: $endfor
</block>

<block type="callout" kind="note">
text: The count has to be a whole number, otherwise the bot posts an error and treats the loop as if it ran zero times. $for and $endfor always travel in pairs, and one loop can sit inside another as deep as you like.
</block>
</dash>

<details>
syntax: $for[count]
param: count|number|Required|How many times to run the block; anything below zero skips it
</details>
