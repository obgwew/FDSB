<dash>
name: $sub
desc: Takes the first number and subtracts the rest one after another.
category: Math & Numbers

<block type="text" title="How does the command work?">
text: $sub needs two or more numbers. It starts at the first one and takes each following number away from it, so $sub[10; 3; 2] leaves you with 5. The answer is a value rather than a message, so you can stand it on its own or drop it straight into the middle of a sentence.
</block>

<block type="list" title="How to use it in the app">
item: Open the Commands tab
item: Tap + to start a new command
item: Give it a name in the Name field
item: Set the Prefix field to !sub
item: Write your script in the editor
item: Paste the line below wherever you need it
item: Tap Save
</block>

<block type="code" title="Syntax">
text: $sub[a; b; ...]
</block>

<block type="code" title="Ready-to-copy Example">
text: $sendMessage[Result is $sub[10; 3]]
</block>

<block type="callout" kind="note">
text: Two numbers at the very least, and a letter anywhere in the list stops the whole thing with an error. An empty slot counts as zero, which quietly shifts your result.
</block>
</dash>

<details>
syntax: $sub[a; b; ...]
param: a|number|Required|The number you start counting down from
param: b|number|Required|The first number to take away; every later part is taken away as well
</details>
