<dash>
name: $editIn
desc: Waits a set time, then swaps the text of the message the bot sent last.
category: Timing & Delays

<block type="text" title="How does the command work?">
text: The bot pauses for the length you give it — seconds, minutes, hours or days — and then rewrites its own most recent message. That makes it easy to post a placeholder like Loading... and replace it once the work is done. The message it changes has to be one the bot posted during the same run.
</block>

<block type="list" title="How to use it in the app">
item: Open the Commands tab
item: Tap + to start a new command
item: Give it a name in the Name field
item: Set the Prefix field to !welcome
item: Write your script in the editor
item: Paste the line below wherever you need it
item: Tap Save
</block>

<block type="code" title="Syntax">
text: $editIn[time; newMessage]
</block>

<block type="code" title="Ready-to-copy Example">
text: $sendMessage[Loading...]
text: $editIn[5s; Done!]
</block>

<block type="callout" kind="note">
text: The wait is written as a number and a unit: 5s, 10m, 2h, 1d. Anything in another shape is refused. Only the text is replaced — an embed or buttons already sitting on the message are left alone.
</block>
</dash>

<details>
syntax: $editIn[time; newMessage]
param: time|text|Required|How long to wait, as a number and a unit: 5s, 10m, 2h, 1d
param: newMessage|text|Required|The text that should be there once the wait is over
</details>
