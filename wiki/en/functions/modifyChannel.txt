<dash>
name: $modifyChannel
desc: Renames, rearranges or moves a channel in the current server.
category: Channel Management

<block type="text" title="How does the command work?">
text: The first part picks the channel, and everything after it follows in one fixed order: name, topic, age-restriction switch, position, then category. Leave any of those empty and that setting is left alone, which means you can change one thing per call. Nothing is posted when it finishes, so the confirmation is the channel itself looking different.
</block>

<block type="list" title="How to use it in the app">
item: Open the Commands tab
item: Tap + to start a new command
item: Give it a name in the Name field
item: Set the Prefix field to !tidy
item: Paste the code below into the editor
item: Tap Save
</block>

<block type="code" title="Syntax">
text: $modifyChannel[Channel ID; (Channel Name; Topic; Make NSFW?; Position; Category ID)]
</block>

<block type="code" title="Ready-to-copy Example">
text: $modifyChannel[123456789012345678; Announcements; Welcome messages; no; 2; 987654321012345678]
</block>

<block type="callout" kind="warning">
text: It needs a server around it, and your bot needs Manage Channels on the channel being changed. Names stop at 100 characters and topics at 1024, and a category can never be tucked inside another category.
</block>

<block type="callout" kind="note">
text: Answer the age-restriction slot with yes, no, true or false. Writing none as the topic wipes the current one, while none, 0 or null in the category slot takes the channel back out of its category. Supply nothing to change and the bot tells you no changes were given.
</block>
</dash>

<details>
syntax: $modifyChannel[Channel ID; (Channel Name; Topic; Make NSFW?; Position; Category ID)]
param: channelID|snowflake|Required|The channel to change, as an @channel mention or its ID
param: name|text|Optional|New name for the channel
param: topic|text|Optional|New topic; write none to wipe the current one
param: nsfw|text|Optional|Age restriction switch: yes, no, true or false
param: position|integer|Optional|New spot for the channel in the sidebar
param: categoryID|snowflake|Optional|Category to drop the channel into; none, 0 or null removes it
</details>
