<dash>
name: $replaceRegex
desc: Swaps runs of matching characters in a piece of text for something you choose.
category: String Utilities

<block type="text" title="How does the command work?">
text: Hand it some text, a character rule and a replacement, and the bot prints the text back with every match swapped for the replacement. A rule in square brackets such as [aeiou] catches any of those letters, -[aeiou] catches everything that is not one of them, and any other rule is matched as plain text exactly as you typed it. Because a rule catches whole runs, Banana with the vowels rule becomes B*n*n* rather than six separate stars.
</block>

<block type="list" title="How to use it in the app">
item: Open the Commands tab
item: Tap + to start a new command
item: Give it a name in the Name field
item: Set the Prefix field to !shout
item: Write your script in the editor
item: Paste the line below wherever you need it
item: Tap Save
</block>

<block type="code" title="Syntax">
text: $replaceRegex[text; rule; replacement]
</block>

<block type="code" title="Ready-to-copy Example">
text: $replaceRegex[Banana; [aeiou]; *]
</block>

<block type="callout" kind="note">
text: Runs are matched greedily, so several characters in a row collapse into a single copy of your replacement. Leave the replacement empty to strip characters out completely, and remember that a result which ends up entirely blank is never posted to the chat.
</block>
</dash>

<details>
syntax: $replaceRegex[text; rule; replacement]
param: text|text|Required|The text to work on
param: rule|text|Required|Character rule. [chars] matches those characters, -[chars] matches everything else, anything else is matched literally
param: replacement|text|Required|What to put in place of each match
</details>
