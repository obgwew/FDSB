<dash>
name: $thumbnail
desc: Puts the small picture in the corner of the card your command builds.
category: Embed Builder

<block type="text" title="How does the command work?">
text: $thumbnail sets the picture that sits in the top right corner of a card. Hand it any text holding a web address and the first address inside it is used, so a link you built earlier can be dropped straight in. Add a number at the end when one command builds several cards and you want it on the second or the third.
</block>

<block type="list" title="How to use it in the app">
item: Open the Commands tab
item: Tap + to start a new command
item: Give it a name in the Name field
item: Set the Prefix field to !thumbnail
item: Write your script in the editor
item: Paste the line below wherever you need it
item: Tap Save
</block>

<block type="code" title="Syntax">
text: $thumbnail[url;(index)]
</block>

<block type="code" title="Ready-to-copy Example">
text: $title[Server stats]
text: $thumbnail[https://example.com/chart.png]
</block>

<block type="callout" kind="note">
text: The address has to start with http:// or https://, and punctuation left over after it is trimmed off for you. Nothing usable in the text and the bot stops with an error rather than sending a card with no picture.
</block>
</dash>

<details>
syntax: $thumbnail[url;(index)]
param: url|text|Required|Text holding the picture address, starting with http:// or https://
param: index|number|Optional|Which card to add it to when you build several; the first one is used by default
</details>
