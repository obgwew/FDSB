<dash>
name: $untimeout
desc: Lifts an active timeout off a member and hands their normal permissions straight back.
category: Moderation

<block type="text" title="How does the command work?">
text: Give it a mention or a user ID and the bot clears whatever timeout that member is currently sitting under, so they can talk, react and join voice again straight away. Somebody who was not timed out is simply left alone, and the command finishes quietly. The bot has to be allowed to do it, which means the Moderate Members permission and a role sitting above the person you are clearing.
</block>

<block type="list" title="How to use it in the app">
item: Open the Commands tab
item: Tap + to start a new command
item: Give it a name in the Name field
item: Set the Prefix field to !untimeout
item: Paste the code below into the editor
item: Tap Save
</block>

<block type="code" title="Syntax">
text: $untimeout[user]
</block>

<block type="code" title="Ready-to-copy Example">
text: $untimeout[@user]
</block>

<block type="callout" kind="note">
text: A member with no active timeout comes out of this untouched, and the bot posts no confirmation either way. Pair it with $timeout if you want the matching pair of actions in the same command.
</block>

<block type="callout" kind="warning">
text: Without Moderate Members, or with the bot's highest role below the target's, Discord turns the request down and the bot reports it in the channel. It only works inside a server, so trying it in a direct message ends in an error.
</block>
</dash>

<details>
syntax: $untimeout[user]
param: user|text|Required|The member to clear, written as an @mention or a user ID
</details>
