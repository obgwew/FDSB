<dash>
name: $guildName
desc: Gives you the name of the server where the command was typed.
category: Info

<block type="text" title="How does the command work?">
text: $guildName puts the name of the server the command was typed in straight into your line of text. Put it in the middle of a sentence and the bot drops the name in between, which makes greetings and channel announcements read as if you typed the server name yourself. Nothing else is added to it, so it comes out as one plain piece of text.
</block>

<block type="list" title="How to use it in the app">
item: Open the Commands tab
item: Tap + to start a new command
item: Give it a name in the Name field
item: Set the Prefix field to !welcome
item: Write your script in the editor
item: Paste the line below wherever you need it
item: Tap Save
</block>

<block type="code" title="Syntax">
text: $guildName
</block>

<block type="code" title="Ready-to-copy Example">
text: Welcome to $guildName!
</block>

<block type="callout" kind="note">
text: Send the command in a direct message and there is no server to name, so the bot writes DM where the name would normally appear.
</block>
</dash>
