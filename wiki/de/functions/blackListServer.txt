<dash>
name: $blackListServer
desc: Sperrt diesen Befehl in jedem Server auf der Liste.
category: Zugriffskontrolle

<block type="text" title="Wie funktioniert der Befehl?">
text: $blackListServer prüft, auf welchem Server der Befehl ausgeführt wird, und vergleicht ihn mit den von Ihnen aufgeführten. Ist der aktuelle Server ein Treffer, zeigt der Bot Ihre Ablehnungsnachricht — oder eine Standardnachricht, falls Sie keine angegeben haben — und der Rest des Befehls wird verworfen. Steht er nicht auf der Liste, wird nichts ausgegeben und das Skript läuft einfach weiter. So halten Sie einen Befehl sauber von bestimmten Orten fern, während er anderswo offen bleibt.
</block>

<block type="code" title="Syntax">
text: $blackListServer[server; ...; message]
</block>

<block type="code" title="Kopierfertiges Beispiel">
text: $blackListServer[123456789012345678; Sorry, this server cannot use the command!]
</block>

<block type="callout" kind="note">
text: Ein Server kann als ID oder als Name angegeben werden, wobei der Name ohne Beachtung der Groß-/Kleinschreibung erkannt wird. Mehrere Server trennen Sie durch Semikolons. Alles bis zum letzten Argument gilt als Server, das letzte Argument ist daher für Ihre eigene Ablehnungsnachricht bestimmt.
</block>

<block type="callout" kind="warning">
text: Wenn die Prüfung erfolgreich ist, stoppt der Befehl an dieser Stelle — keine Zeile darunter wird ausgeführt. Lassen Sie die eigene Nachricht weg, greift der Bot auf eine eigene Formulierung zurück.
</block>
</dash>

<details>
syntax: $blackListServer[server; ...; message]
param: server|text|Erforderlich|Die gesperrten Server als IDs oder Namen, durch Semikolons getrennt
param: message|text|Optional|Eine Nachricht, die statt der Standard-Ablehnung angezeigt wird, wenn der Server zutrifft
</details>
